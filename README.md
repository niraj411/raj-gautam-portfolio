# Raj Gautam Portfolio | Himalaya LLC

Personal portfolio website showcasing full-stack development projects and property management services.

**Live site:** [rajgautam.com](https://rajgautam.com)

## Tech Stack

- **React** - Frontend framework
- **Framer Motion** - Animations and transitions
- **tsparticles** - Interactive particle background
- **react-icons** - Icon library

## Featured Projects

- **iMasala** - Full-stack restaurant ordering platform with real-time order management
- **Tandoori IDS** - ML-powered intrusion detection system for small business networks
- **Tandoori Kitchen E-Commerce** - Restaurant website with online ordering integration

## Development

```bash
# Install dependencies
npm install

# Run development server
npm start

# Build for production
npm run build
```

## Deployment

Built files are deployed to production via the `build` directory.
